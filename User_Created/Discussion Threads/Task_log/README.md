# 💬 Discussion Threads & Planning Logs (`Task_log/`)

This directory houses chronological planning discussions, vendor interview transcripts, meeting minutes, and agent-user conversation logs.

---

## Formatting Standard

Discussion logs in this directory follow the standardized Query/Response hierarchy formatted via [`UserUtility`](file:///d:/GitHub_Repo/Sree_Krushna/User_Created/Discussion%20Threads/UserUtility/):
- **Top-Level H1 Sections:** `# Query X.Y - <Topic>` and `# Response X.Y - <Topic>`
- **Internal Headers:** Shifted down (`##`, `###`, `####`) to maintain clean AST outline hierarchies.
- **VS Code Tasks:** Run `Format Chat Log` or `Adjust Markdown Headers` to format logs in-place.
