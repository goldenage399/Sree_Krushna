## 🚨 **MANDATORY CHECK QUESTIONS**

### **🔍 Pre-Implementation Evaluation**
Before any suggestion or development work, Claude MUST ask and answer:

```yaml
production_first_checklist:
  blocking_assessment:
    question: "Does this block user access to core functionality?"
    evaluation_criteria:
      - "Can users complete primary workflows without this?"
      - "Does this prevent basic application usage?"
      - "Is this required for minimum viable experience?"
    
  goal_achievement_check:
    question: "Can users accomplish their primary goal without this?"
    evaluation_criteria:
      - "What is the core user goal this addresses?"
      - "Are there workarounds for this functionality?"
      - "Does this solve a must-have vs nice-to-have need?"
    
  launch_necessity:
    question: "Is this needed for Day 1 launch?"
    evaluation_criteria:
      - "Does this affect core business functionality?"
      - "Is this legally or business-critically required?"
      - "Would users abandon the product without this?"
```
