🔒 Decorator Cockpit — Firestore Content Seed Utility

Dynamic Migration Tool (SEC-1 Remediation, AC-DEC-2026-012).
Reads source JSON directly from disk (cockpit_src/data/*.json) and pushes it into Firestore's cockpit_content collection. This guarantees zero data drift.

How to run: from the repo root, start SERVE_ROOT=. node scripts/dev-server.cjs (PowerShell: ='.'; node scripts/dev-server.cjs), then open http://localhost:5000/scripts/seed-cockpit-firestore.html.
Never copy or deploy this file into public/.
